Given a list of user support tickets, identify which ones are bugs vs. feature requests and assign a priority (P1/P2/P3).

Think through each ticket step by step before assigning. For each ticket, work through these three questions out loud:
1. Is this a bug (existing behavior is broken) or a feature request (new capability)?
2. What is the user impact? P1 = many users blocked, P2 = some users affected with workaround, P3 = nice-to-have.
3. Is anything ambiguous about the report? If yes, state the assumption you are making.

After reasoning through each ticket, give the final classification on its own line.

Tickets:
- "App crashes when uploading files larger than 10MB"
- "Add dark mode to the dashboard"
- "Login button doesn't work on Safari 16"
- "Would be nice to export data as CSV"
- "Sometimes the app feels slow"
- "Notifications should be configurable per project"
