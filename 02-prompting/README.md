# 02 — Prompting

A prompt is a specification. Vague specs produce vague output. This module teaches what makes a prompt precise: role, context, output format, constraints, and examples. The exercises progress from identifying what is missing in a one-liner prompt to writing a meta-prompt that generates structured prompts.

| Exercise | Time | What you build |
|---|---|---|
| Beginner | 15 min | Rewrite a vague one-liner as a structured prompt; compare outputs |
| Intermediate | 30 min | Apply chain-of-thought, few-shot, and role-prompting to the same task; document when each changes output quality |
| Advanced | 50 min | Write a meta-prompt: a prompt that takes a rough task description and produces a production-quality structured prompt |
