# 02 — Prompting

Write prompts as specifications.
Vague specs produce vague output.
Precise prompts define role, context, output format, constraints, and examples.

| Exercise | Time | What you build |
|---|---|---|
| Concept | 15 min | Rewrite a vague one-liner as a structured prompt |
| Apply | 30 min | Compare chain-of-thought, few-shot, and role-prompting |
| Extend | 50 min | Write a meta-prompt that generates structured prompts |
