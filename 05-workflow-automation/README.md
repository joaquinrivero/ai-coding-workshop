# 05 — Workflow Automation

The payoff. This module applies Model + Context + Tools + Prompts to a real recurring task. You bring the task. The exercises progress from a simple bash wrapper to a fully parameterized pipeline that runs on a schedule or trigger.

| Exercise | Time | What you build |
|---|---|---|
| Beginner | 15 min | Identify one weekly manual task; write a prompt + bash wrapper to automate it; run it |
| Intermediate | 30 min | Add a scoped CLAUDE.md to the automation; run it 3 times; measure output consistency |
| Advanced | 50 min | Build a programmable pipeline: prompt.md + wrapper script that runs as a scheduled or triggered job |
