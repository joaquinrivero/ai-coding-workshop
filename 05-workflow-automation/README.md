# 05 — Workflow Automation

Automate one recurring task. Combine Model, Context, Tools, and Prompts. Start with a slash command. Extend it into a scheduled pipeline.

| Exercise | Time | What you build |
|---|---|---|
| Concept | 15 min | Run the completed `/my-workflow` command |
| Apply | 30 min | Add scoped context and measure output consistency |
| Extend | 50 min | Build a scheduled or triggered pipeline |
