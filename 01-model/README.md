# 01 — Model

Choose models by cost and capability.
Haiku is fast and cheap.
Opus is slow and thorough.
Sonnet sits between them.
Most tasks do not need Opus.

| Exercise | Time | What you build |
|---|---|---|
| Concept | 15 min | Compare Haiku, Sonnet, and Opus on the same prompt |
| Apply | 30 min | Write a classifier prompt that recommends a model |
| Extend | 50 min | Build a two-stage pipeline that routes by task complexity |
